# 🛡️ Angtong Port Scanner

A fast, multi-threaded command-line network port scanner written in Python.  
**Angtong** allows users to scan target IP addresses for open ports using customizable ranges and thread counts for optimized performance.

## 🚀 Features
- **Multi-threaded Scanning:** High-speed scanning using Python's `threading` module.
- **CLI Interface:** complete command-line control using `argparse`.
- **Hostname Resolution:** Automatically resolves URLs (e.g., google.com) to IP addresses.
- **Customizable:** Users can define start/end ports and the number of threads.
- **Thread-safe Output:** Clean output handling prevents jumbled text during concurrent scans.
